# 麦爸的思想智慧库

> 麦爸出品，必属精品 —— 一份可按主题、性价比、成本维度筛选的**个人智慧合集**。
> 在线访问：https://xie666888.github.io/maiba-wisdom

## 这是什么

**两个库，两套来源，互不混合。** 页面顶部可以来回切换，一眼分得清哪条是自己的、哪条是读来的：

| 库 | 装什么 | 数据源目录 | 来源标记 | 视觉 |
|---|---|---|---|---|
| **我的智慧** | 麦爸本人的实战复盘与方法论（第一人称） | `book/` | `origin: self` | 蓝色体系 |
| **读书外脑** | 成庆佛学著作的读书卡片（第三人称书摘） | `reading/` | `origin: book` | 青色体系 |

每条内容是一个 `.md` 文件，带标签（主题 / 性价比 / 换回什么 / 花钱 / 花时间 / 要毅力），
左侧按这些标签筛选，条目可点开看详情。

**读书外脑另有两个碎片学习的功能：**

- **随机抽一张** —— 不用想读哪一讲，点一下就有。给"只有五分钟"准备的入口。
- **已读进度** —— 展开一张卡就自动记为已读，侧边栏显示进度条与百分比，还能「只看未读」。
  进度存在浏览器本地（localStorage），零后端、跨设备不同步（各有各的进度）。

纯静态、零依赖、零后端，挂在 GitHub Pages 上，改完内容推上去就更新。

```
book/                    ← 我的智慧（每个文件一条，带 frontmatter）

  01-renshengjieyou/     ← 读书外脑 · 人生解忧 44 张（rs-01 ~ rs-44）
  02-anxinzhidao/        ← 读书外脑 · 安心之道 10 张（ax-01 ~ ax-10）

  entries.json           ← 由 build.mjs 自动生成，页面读取它
  app.js                 ← 双库切换 + 筛选 + 渲染 + 随机抽卡 + 已读进度
  style.css              ← 蓝黄白主题（我的智慧） / 青色（读书外脑）

_raw/                    ← 本地私有：微信导出 + EPUB 全文（.gitignore，不发布）
```

## 怎么加一条

### A. 加「我的智慧」

1. 在 `book/` 里新建 `.md`，文件名用数字前缀好排序，例如 `31-xxx.md`。
2. 按模板写 frontmatter + 正文：

```markdown
---
id: unique-english-id
title: 一句话讲清这条智慧（动词开头最佳）
theme: AI赋能          # 主题
level: 极高            # 极高 / 高 / 一般（性价比）
value: [钱, 时间精力]  # 换回什么：钱 / 时间精力 / 人身自由 / 认知 / 关系 / 内心
spend_money: [不花钱]  # 不花钱 / 少花钱 / 多花钱
spend_time: [顺手]     # 顺手 / 几小时 / 每天占用
spend_will: [不用毅力] # 不用毅力 / 一点毅力 / 很多毅力
tags: [AI, 生意]       # 任意标签，用于搜索
date: 2026-09
origin: self
---

正文用 markdown 写：段落、**加粗**、> 引用、- 列表。
结尾加一句「说人话」把道理翻成日常说法。

> 源自 · 群名 日期
```

### B. 加「读书卡片」

1. 源文本放 `_raw/reading/<书名拼音>/`（不进仓库），用 `_raw/reading/_extract.py` 从 EPUB 切分。
2. 按 `_raw/reading/_card_spec.md` 的规范提炼，落到 `reading/<序号-书名拼音>/` 下：

```markdown
---
id: rs-09
title: 生活不是重复，是心太粗糙了
theme: 苦与烦恼        # 佛学入门 / 苦与烦恼 / 无我与执 / 缘起与业力 / 空与般若
                      # / 禅修实修 / 慈悲与菩萨道 / 生死与安顿 / 成庆访谈
level: 高
value: [认知, 内心]
spend_money: [不花钱]
spend_time: [几小时]   # 顺手（2 分钟读完）/ 几小时（义理需消化）/ 每天占用（需日常练习）
spend_will: [一点毅力]
tags: [无常, 觉察]
date: 2026-09
origin: book
book: 人生解忧：佛学入门四十讲
author: 成庆
chapter: 第8讲 世界是“常”还是“无常”？（无常）
---

## 这一讲在讲什么
## 关键概念
## 带走一句

> 原文：「逐字引文，≤80 汉字」
```

3. 重新生成数据并发布：

```bash
node build.mjs        # 刷新 assets/entries.json
git add -A
git commit -m "add: 新卡片"
git push
```

推送后约 1 分钟，站点自动更新。

> 注意：`order`（页面上的 `#序号`）由 `build.mjs` 按**同一库内的排序位置**自动生成，
> 不必手写，手写了也会被覆盖——这保证了「我的智慧」里是 1–30、读书外脑里是 1–54，不会串号。

## 散落内容怎么整理进来

飞书 / 笔记 / 聊天里的碎片，先归成"一条一个观点 + 一句说人话"，再按上面模板落成 `.md`。
宁可一次只沉淀一两条真有用的，也不要把碎片原样堆进来。

## 本地预览

```bash
python -m http.server 8000   # 然后浏览器开 http://localhost:8000/
```

> 注意：必须用 http 打开（本地服务器或 GitHub Pages），直接双击 `index.html` 会因浏览器安全策略读不到 `entries.json` 而空白。
